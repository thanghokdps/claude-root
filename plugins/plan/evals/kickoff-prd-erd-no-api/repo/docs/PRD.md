# PRD — Class booking

## Problem
Yoga studio members book classes by phone. Staff lose time and double-book rooms.

## Users
Members (book and cancel classes) and studio staff (manage the timetable).

## Top tasks
1. A member books a class: "A member can reserve one seat in a class until 2 hours before it starts."
2. A member cancels: "Cancelling at least 2 hours ahead refunds the credit."
3. Staff publish a weekly timetable.
4. A member pays for a 10-class pack by card through our payment provider, Stripe.

## Out of scope
Waitlists, mobile app, multi-studio support.

## Acceptance
A class never has more bookings than seats.
