# thang-kit

Everything: installs all nine thang-* role plugins.

## Install

```
/plugin marketplace add thanghokdps/claude-root
/plugin install thang-kit@thang-kit
```

Also installs: `thang-core`, `thang-plan`, `thang-review`, `thang-dev`, `thang-ship`, `thang-agent`, `thang-lead`, `thang-guards`, `thang-progress`.

All plugins: [`../README.md`](../README.md).
