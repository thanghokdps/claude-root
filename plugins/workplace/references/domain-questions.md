# Workplace need questions

Asked by `/kickoff` and `/brainstorming` in a `Domain: workplace` repo, one per turn, as options with the recommended one first. Ask the need; the description carries what it maps to. Skip any the requirements or the code already answer.

| Need question | Options → maps to |
|---------------|-------------------|
| Who approves a request? | Their manager (Recommended) → manager from the org chart · Anyone the requester picks → requester-chosen approvers (a policy, recorded) · Several people, all must agree → multi-level, every approver decides |
| What if the approver is away? | Someone covers for them (Recommended) → delegation with dates · An admin steps in → admin override, audited · Requests wait → no delegation, plus an expiry reminder |
| Do staff work in more than one office or time zone? | One office → one business time zone in config · Several offices, same zone → office per employee, shared holidays · Several zones → time zone and holidays per office |
| How is leave counted? | Working days only, half days allowed (Recommended) → business-day count, 0.5 unit · Every calendar day → calendar count · Hours → hour unit, working hours per office |
| Can people request more leave than they have? | No (Recommended) → pending held against the balance at submit · Yes, as unpaid → unpaid leave type outside the balance · Yes, borrowed from next year → negative balance policy |
| Who sees a request? | The requester, approvers and people they copy (Recommended) → record-level visibility · The whole team → team-scoped list · HR sees everything → HR role with audited reads |
| Does it sync with an HR system? | No, we manage people here (Recommended) → local employees and org chart · Yes, people come from it → read-only sync, the HR system wins · Yes, both ways → integration contract, high-risk lane |
| When must orders or bookings be in? | A fixed time the day before or same morning → server cutoff per office · Any time → no cutoff, change notifications to staff · Depends on the item → cutoff per reservation type |
